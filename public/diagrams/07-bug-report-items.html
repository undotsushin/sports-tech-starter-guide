バグレポートに必須の5項目
1. 発生環境
  • OS (Windows / Mac / iOS / Android)
  • ブラウザ (Chrome / Safari / 等)
  • デバイス (PC / スマホ / タブレット)
  • 画面サイズ
2. 再現手順
  • 1. ○○にアクセス
  • 2. △△をクリック
  • 3. □□を入力
  • → 誰でも同じ結果になる手順
3. 期待する動作
  • 本来はこうなるはず
  • 正常な動作の説明
4. 実際の動作
  • 実際にはこうなった
  • エラーメッセージの全文
5. スクリーンショットまたは動画
  • 画像: 問題が起きている画面
  • 動画: 操作の様子 (loom等)
