**簡単に言うと**: 最も有名で汎用性が高いAI

- 有料版: 月20ドル（GPT-4、画像生成DALL-E付き）

## 8.2 プロンプトエンジニアリング実践

**簡単に言うと**: AIから最高の回答を引き出すための質問テクニック

### 良いプロンプトの6要素

![良いプロンプトの6要素](/images/ai-usage/prompt-elements.png)

### 悪いプロンプト vs 良いプロンプト

**例1: 資料作成**

```
× 悪いプロンプト:
「資料作って」

問題点:
- 何の資料か不明
- 誰向けか不明
- どんな内容か不明
- 形式が不明

○ 良いプロンプト:
「あなたは経験豊富な営業資料作成の専門家です。

【依頼内容】
スポーツメディア向けの広告提案資料を作成してください。

【背景】
クライアント: 大手スポーツ用品メーカー
商品: 新作ランニングシューズ（定価15,000円）
ターゲット: 20-30代のランニング愛好家（年収400-600万円）
予算: 月500万円
期間: 3ヶ月キャンペーン

【出力形式】
1. 提案概要（100文字以内）
2. ターゲット分析（200文字）
3. 配信プラン（媒体別予算配分を表で）
4. 期待効果（具体的な数値で）
5. スケジュール（ガントチャート形式で）

【制約】
- 全体で1,500文字以内
- 数値は必ず根拠を示す
- 競合との差別化ポイントを含める」
```

**例2: コード生成**

```
× 悪いプロンプト:
「ログイン機能作って」

○ 良いプロンプト:
「あなたは経験豊富なWebエンジニアです。

【依頼内容】
Node.js + Expressでログイン機能を実装してください。

【要件】
- メールアドレスとパスワードでログイン
- パスワードはbcryptで暗号化
- JWTでセッション管理
- ログイン失敗は3回まで（それ以上はロック）
- ログイン履歴をデータベースに保存

【技術スタック】
- Node.js 18.x
- Express 4.x
- MongoDB
- JWT

【出力形式】
1. コード全文（コメント付き）
2. 必要なnpmパッケージ
3. 環境変数の設定例
4. テストコード
5. セキュリティ上の注意点

【制約】
- ES6記法を使用
- エラーハンドリングを必ず含める
- セキュリティベストプラクティスに従う」
```

### プロンプトテンプレート集

**営業メール作成**

```
あなたは経験豊富な営業担当者です。

【依頼内容】
以下の条件でクライアントへのフォローメールを作成してください。

【背景】
- クライアント: [会社名]
- 担当者: [名前]
- 前回の商談日: [日付]
- 商談内容: [内容]
- 現在の状況: [状況]

【目的】
- [目的を記載]

【制約】
- 200文字以内
- 丁寧だが親しみやすいトーン
- 具体的なアクション（次回会議の日程調整など）を含める

【出力形式】
件名:
本文:
```

**企画書作成**

```
あなたは経験豊富な企画担当者です。

【依頼内容】
以下の条件で企画書を作成してください。

【背景】
- 目的: [目的]
- ターゲット: [ターゲット]
- 予算: [予算]
- 期間: [期間]
- 期待効果: [期待効果]

【出力形式】
1. 企画概要（100字）
2. 背景・課題
3. ターゲット分析
4. 施策詳細
5. スケジュール
6. 予算配分
7. KPI設定
8. リスクと対策

【制約】
- 全体で2,000文字以内
- 数値は具体的に
- 実現可能性を重視
```

**議事録作成**

```
あなたは議事録作成の専門家です。

【依頼内容】
以下の会議内容から議事録を作成してください。

【会議情報】
- 日時: [日時]
- 参加者: [参加者]
- 議題: [議題]

【会議内容】
[会議の音声文字起こしや箇条書きメモを貼る]

【出力形式】
1. 会議概要
2. 決定事項（番号付きリスト）
3. 保留事項（担当者と期限を明記）
4. 次回アクション（誰が何をいつまでに）

【制約】
- 箇条書きで簡潔に
- 曖昧な表現は避ける
- 担当者と期限を必ず明記
```

**2. メール作成の自動化**

```
定型メールの例

【フォローメール】

「前回の商談（[日付]）でご提案した
[商品名]について、その後いかがでしょうか？

ご検討状況をお聞かせいただけますと幸いです。
何かご不明点があれば、お気軽にお問い合わせください。

次回のお打ち合わせ日程を調整させていただきたく、
ご都合の良い日時を3つほど候補いただけますでしょうか。」

→ このテンプレートを保存しておけば、
  毎回5秒で作成可能
```

**3. 企画のブレインストーミング**

```
アイデア出しのプロンプト例:

「20代女性向けのランニングイベントの企画を10個考えてください。

【条件】
- 予算: 各100万円
- 期間: 各3ヶ月
- 目標参加者数: 各300人
- 開催地: 東京都内
- 差別化ポイント: 他社にない独自性

【出力形式】
各企画について:
1. 企画名（キャッチーに）
2. 概要（100字）
3. 独自性（他社との違い）
4. 予算配分（表で）
5. 期待効果（具体的な数値）
6. リスクと対策

全体で5,000字程度」

→ 30分で10企画が完成
→ 人間が選別・ブラッシュアップ
```

### 制作業務での活用

**1. コンテンツ企画**

```

20個考えてください。

【条件】
- ターゲット: 20-30代の女性
- SEOキーワード: 「ランニング 初心者」
- 文字数: 各30文字以内
- トーン: 親しみやすく、ポジティブ

【タイトルの種類】
- How to系: 5個

- 体験談系: 5個

各タイトルに期待できる検索ボリュームと

→ 10分で20タイトル完成
→ 人間が選んで執筆
```

**2. SNS投稿の最適化**

```
Instagram投稿文の作成:

「以下の商品をInstagramで紹介する投稿文を作成してください。

【商品情報】
- 商品名: ランニングシューズ「〇〇」
- 価格: 15,000円
- 特徴: 軽量、クッション性、デザイン性
- ターゲット: 20-30代女性

【条件】
- 本文: 150文字以内
- ハッシュタグ: 10個
- 絵文字: 適度に使用
- CTA: プロフィールのリンクから購入

【トーン】
- 親しみやすい
- ポジティブ
- 共感を呼ぶ

【出力形式】
1. 投稿文
2. ハッシュタグ
3. 投稿に使う画像の説明（3案）
4. ストーリーズ用のテキスト（3案）」
```

```
【条件】

【出力形式】
1. タイトル（3案）
```

**2. バグ修正**

```
バグの原因特定:

「以下のコードでエラーが発生します。
原因と修正方法を教えてください。

【エラーメッセージ】
TypeError: Cannot read property 'name' of undefined

【コード】
[コードを貼り付け]

【期待する動作】
ユーザー名を表示

【実際の動作】
エラーが発生

【出力形式】
1. エラーの原因
2. 修正後のコード
3. 同様のエラーを防ぐ方法
4. テストコード」
```

```

【観点】
- セキュリティ
- パフォーマンス
- 可読性
- ベストプラクティス

【コード】
[コードを貼り付け]

【出力形式】
1. 問題点（重要度順）
2. 修正案（コード付き）
3. 改善の優先順位
4. 追加すべきテスト」

→ Claudeが得意
```
